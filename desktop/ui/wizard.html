欢迎使用 evo-agent

首次配置只需一分钟；本向导可随时从托盘菜单「LLM 凭据…」重新打开。

① LLM 凭据

粘贴你的模型服务 API Key（如 MiniMax）。凭据将以 Windows 凭据保护（DPAPI）加密后保存在本机用户目录，仅本 Windows 账户可读；不会经过工作台页面，也不会写入日志。没有 Key 可先跳过， 之后仍可使用非对话功能。

更多模型服务（可选，配置后可在对话框切换模型）

为其他模型服务配置 API Key 后，对话/补全会按所选模型自动路由到对应服务。 模型可用范围以工作区准入白名单为准。

② 工作文件夹

agent 的读写都在这个文件夹里进行（缺省在 ，对日常使用不方便）。建议保持缺省或 选择你自己的工作文件夹；之后随时可在对话栏顶部修改。
