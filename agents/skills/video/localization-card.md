# 本地化术语卡

## 定位（何时用）

M4 localization-dub 线 glossary_lock→locale_plan→dub_prep→timing_fit 段：已有内容做翻译配音变换。本卡管**术语一致性与口型时长适配判断**；配音表演归 narration 卡，法务词保护细节（商单合同面）呈上游。

## 前置依赖（声明化引用）

- 引擎 CLI：`engine.py timeline <project_dir>`（原片时间轴——时长适配基准）、`engine.py build <project_dir>`（装配）、`engine.py verify <project_dir>`（核对）
- 阶段链：brief→glossary_lock→locale_plan→dub_prep→timing_fit→locale_assembly→delivery
- 技能：`video-narration`（配音执行与样音闸）、`video-producer`（TTS 可用性与成本）、`video-reviewer`（本地化复核）
- 谓词面：qc_loudness（配音轨响度）/字幕与语音一致率抽检——机器初筛引谓词名

## 作业流程

1. 术语锁定表：原文术语逐条定译法（产品名/专有名词/品牌词/技术词）并锁定——锁定表是整条线的 SSOT，后续任何译文不得偏离；法务词（商标/免责声明/合同约定词）标「法务保护」呈上游确认，AI 不私定译法。
2. 语气与称谓体系定调：目标语言的人称/敬语体系/语气档位一次性定调（记入锁定表附注）——中途改称谓体系=全片重译。
3. 翻译适配时长：译文按原片时间轴分段适配——目标语言膨胀（德/俄常见 +10~30%）时先压缩译句再考虑加速音频；每段译文时长写进 locale_plan。
4. 口型时长适配判断：timing_fit 段逐段核对「译文时长 vs 原口型时长」——超差段落按优先级处置（关键口型段缩译/非关键段接受音频延长），处置记录留痕。
5. 字幕同步再生：字幕从锁定后的译文再生（同源原则——字幕与配音必须同一译文，防两处维护漂移），一致率抽检过 qc 初筛。
6. 本地化回归抽验：抽 3~5 段全链核对（原文→术语表→译文→配音→字幕）五件互证——术语漂移/时长爆表/字幕错位任一命中即全量复查。

## 质量判据

- 机器可查：qc_loudness 过；字幕与配音一致率抽检过；每段译文时长记录与 timeline 对位。
- 人工判断：术语锁定表经上游确认；口型超差段处置记录完整；本地化回归抽验通过。

## 闸提示（何时停待人审）

- 术语锁定表确认（强制首闸——术语表错全片错）；法务词译法；口型超差段量大需裁「缩译 vs 重配」。

## 边界（不做何事+降级路径）

- 不私定法务保护词译法；不为口型硬改语义（术语表与事实优先于口型美观）；不跳术语锁定直接开译。
- 目标语言 TTS 音色不可用时降级路径：产出「字幕-only 本地化版」（译文+字幕齐，配音缺位标注），交 producer 卡裁是否外接 TTS。
