# 全生成资产生成卡

## 定位（何时用）

M2 三线 asset_gen 段：脚本场景逐个转成生成提示词并执行生成、挑选候选。本卡管**提示词工艺与生成判断**；叙事内容归提案卡（提示词只翻译不添改）；GPU 预算归 producer 卡。

## 前置依赖（声明化引用）

- 引擎 CLI：`engine.py shots <project_dir>`（镜头清单）、`engine.py pick <project_dir>`（候选挑选辅助）、`engine.py build <project_dir>`（正式构建）
- 阶段链：…→scene_plan→asset_gen→edit→…（character-animation 线前置 character_design→rig_plan）
- 技能：`video-producer`（GPU 预算与分批判断）、`video-taste`（风格锚定一致性）、`video-reviewer`（候选复核）
- 谓词面：qc_anatomy（手部/骨骼几何，生成畸变高发区）——候选初筛引谓词名

## 作业流程

1. 提示词逐镜头翻译：脚本段→生成提示词——只翻译不加戏：脚本没有的元素不进提示词（防「AI 自由发挥」污染叙事）；每条提示词带风格锚定注的风格关键词（一致性前提）。
2. 负面提示词基线：按镜头内容配负面词（文字水印/多余肢体/畸变面部/画面噪点基线+镜头特配）——特配项注明针对什么风险。
3. 参数选择三判断：分辨率/帧数/候选数——按 producer 卡预算裁候选数（预算紧=少候选多轮选，预算松=多候选一轮选）；种子策略显式记录（复现需要 vs 探索需要）。
4. 生成执行与初筛：候选先过机器初筛（qc_anatomy 手部/面部畸变检测）再人工复筛——畸变候选不进人工筛池，省注意力。
5. 候选挑选分账：机器可查项（几何/分辨率/时长）引谓词；判断项（美学/风格一致/叙事贴合）写挑选理由——每镜头选定一条+理由，备选不删留复审。
6. 风格一致性横查：全部镜头候选选定后横向比对——色调/质感/颗粒度跨镜头漂移即列漂移清单，回 taste 卡裁是否锚定注要更新。
7. 台账同步：每镜头生成参数与选定候选写台账（模型版本/提示词摘要/seed/日期），与 manifest usage 互证——台账不全不进 edit 段。

## 质量判据

- 机器可查：qc_anatomy 初筛记录；台账字段与 manifest usage 互证一致；候选数与预算记录一致。
- 人工判断：每镜头挑选理由在案；风格漂移横查有结论；提示词「只翻译不加戏」抽验无添改。

## 闸提示（何时停待人审）

- 候选全部不合格（需改提示词策略或升格预算）；风格漂移超锚定容差；character 线骨骼规格首次定型（交骨骼数据集前）。

## 边界（不做何事+降级路径）

- 不改脚本内容（发现脚本问题退提案卡）；不超预算生成（预算墙是 producer 卡硬闸）；不跳过 qc_anatomy 初筛直接人工挑（手部畸变肉眼易漏）。
- 生成腿不可用时降级路径：产出「镜头-提示词」全量清单+参数建议供复跑，标注「生成未执行」，不伪造候选图。
